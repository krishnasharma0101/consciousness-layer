A graph-theoretic memory layer between two LLM calls: formalism, self-audit and pre-registered evaluation

Krishna Sharma · the "Sandwich Model" and its Consciousness Layer (theory v1.1) · repository consciousness-layer · CPU only, no paid APIs

1 · Formalism

20 math issues found in a self-audit, each with a fix
  • A self-audit of the original paper found 20 math issues (static Φ, no activation rule, λ pointing both ways, unbounded C and R, an undefined A* heuristic, and (1+E) ≤ 0). Each one has a concrete fix.
  • Theory v1.1: every quantity is defined and bounded. Activation is personalised PageRank, Cnorm ∈ [0, 1], and the A* heuristic never overestimates.
  • 52 unit tests pass (STATUS.md, 3 Nov 2026).

2 · Evaluation protocol

6 pre-registered experiments
  • Every experiment after v0 was pre-registered: hypothesis, numeric prediction and falsifier written down before running. Across those runs, 28 predictions held and 10 failed.
  • Three datasets (v0 synthetic, LongMemEval-S, LoCoMo), shuffled-W and random-topology controls, S/T/E/R/A* ablations, paired bootstrap CIs, Holm correction.
  • Full audit trail: lab notebook, a git commit per run, a 43-claim ledger, and one aborted run that is logged rather than hidden.
6 pre-registered experiments, plus the v0 backfill, 2 preprocessing runs, 1 smoke test and 1 aborted attempt. Prediction counts are transcribed item by item from the notebook's prediction checks.

3 · Findings

+0.102 all-evidence@10, RRF over cosine (LoCoMo)
  • Hybrid retrieval wins. RRF(BM25, cosine) beats dense cosine by +0.102 [0.081, 0.124] on LoCoMo (N = 1,536) and BM25 by +0.026, both pre-registered.
  • The graph layer gave no significant gain, as a first stage, a weighting or a re-ranker. Multi-hop: +0.018 [−0.004, +0.043], below the +0.03 bar. Real W ≈ shuffled W.
  • Draft contamination: passing a wrong draft to the refine step cost 94 vs 114/120 on v0. It did not show up on LoCoMo.
  • Cnorm is a weak error signal (AUROC 0.63–0.68, below plain max-cosine).

4 · What's next

7B reader run is the next test
  • Run one 7B reader (e.g. on a free Colab/Kaggle GPU) to answer "maybe it needs a bigger model".
  • Multi-hop retrieval that is aware of evidence (query decomposition), since RRF still misses ≥ 1 evidence turn on ~90% of multi-hop questions.
  • A held-out confirmation of the small real-W vs shuffled-W hint on LoCoMo frac@10 (uncorrected).
  • Write-up as a workshop or arXiv paper: an honest negative result plus the formalism.

What this work does not claim. It does not show that the graph layer beats retrieval baselines. On every pre-registered test it did not. It says nothing about consciousness either. Φ, Φdyn and Cnorm are engineering quantities on a memory graph, and "consciousness" appears only as the motivation of the original paper. The contribution is a precise, testable formalism and an honest, auditable evaluation of it.
