    5. Edge weight Wij

    Wij = Sij · Tij · Fij · Rij / Wmax
    S = max(0, cos) · T = 2−|ti−tj|/h · F = 1 + κ(|ei|+|ej|)/2 · R ∈ [1, 2]
    Ablated factors are set to 1 and dropped from Wmax, as in the code. R ≡ 1 in every logged experiment (no learning). The reinforce button only shows the bounded update rule; no run used it. The edge set (top-k by τ) does not change when you toggle factors. Only the weights change.

    What the experiments found (logged runs)

    On LoCoMo multi-hop (N=277, R-2026-11-03-03), all-evidence@10: RRF 0.105, graph re-rank (S-only) 0.105 (Δ 0.000 [0, 0]), strong graph re-rank 0.123 (Δ +0.018 [−0.004, +0.043], not significant). The graph as first stage scored 0.079. Real W was no better than shuffled W. This page shows how the layer works. It does not show that it beats retrieval.
